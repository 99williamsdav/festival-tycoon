# M0.07 — One agent traverses the farm

Status at authoring: Not started. Milestone: M0 foundation.

## Assignment

One simulation-owned agent reaches a destination around obstacles, with the same route result headless and rendered.

Dependencies: M0.06 accepted.

Read [shared execution rules](README.md#shared-execution-rules), then these targeted sections of the repository-root documents: TECHNICAL_SPEC.md §§4–7; CONTENT_AND_BALANCE.md §§1, 4 (walking-speed definition). Read additional sections only when needed to resolve a concrete dependency.

## Scope

- Implement the static traversal grid, integer position state and deterministic eight-neighbour A* with no diagonal corner cutting.
- Use the specified initial movement units; preserve fractional movement remainder where integer rounding would otherwise bias speed.
- Add minimal Idle/Travelling/Arrived/NoRoute states and a destination command.
- Render/interpolate the agent from read state; mesh animation cannot advance position.
- Add only baseline surface metadata/terrain costs now; rainfall, wear accumulation and crowd separation follow later.
- Extend save snapshots/hash to route, movement progress, action and terrain state.

## Acceptance checks

1. Agent reaches a reachable target without entering a blocked cell or cutting diagonally between obstacles.
2. An unreachable target yields bounded NoRoute feedback, not endless search or teleportation.
3. Equivalent fixture headless/rendered at the same tick produces the same authoritative state.
4. Saving halfway through travel and resuming matches uninterrupted arrival/state.
5. Inspect walking pace at 1x-equivalent playback: roughly 25 real seconds across 60 visual metres as specified.
6. Two equal-cost routes select consistently; changing frame pacing does not select another route.

These are required outcomes, not a prescribed test implementation. Add meaningful automated checks where feasible and report manual observations honestly.

## Exclusions

No social AI, dynamic construction, crowd pressure, route caching framework, navmesh or full stuck-agent rescue.

## Demonstration

Send one agent from the gate around a barn to the service point, then try a blocked target.
