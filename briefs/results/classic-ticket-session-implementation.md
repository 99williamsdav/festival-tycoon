# Classic booking session integration — review candidate

15 October 2026. This is the economic/phase slice of the active booking → ticket sales → site-preparation commission. It builds on reviewed pure-model commit 546e132d and journal commit 113f5b03. The user's approved refund/cancellation terms are recorded in `briefs/classic-booking-ticket-phases.md`. This is not a UI or Windows delivery acceptance.

Classic now begins with the actual £200 starter loan or actual carried cash, before ticket revenue. After the existing forecast/perk sequence, its free draft contains three acts and a price. Guidance gives capacity 25, a sales range, overlapping popularity, band fees, conservative setup cash and a risk flag based on essential facilities/crew and the existing £100 overdraft. Risk does not reject confirmation. Confirmation resolves the keyed market once, pays the authoritative catalogue quotes and replaces capacity candidates with the actual ticket holders. There is no gameplay RNG consumption or retrospective facility sales.

The saved command journal derives all booking money; session cash remains the sole spendable balance. Rebooking releases recorded fees, pays new current quotes and refunds only the incremental highest-severity target against the original announcement. Retained identities cannot rewrite quotes. Empty post-sale slots are permitted with an explicit all-zero sentinel, receive the same loss assessment and block opening until refilled. Reordering retained acts is free. Refunds and disappointment do not reset when the original lineup returns. Original ticket-holder genre expectations remain tied to the announcement.

Cancellation refunds remaining tickets and active band contracts, clears the unpaid site draft, loses five reputation with a zero floor and returns to booking the same ordinal/market/weather. It does not add debt or end the campaign. A legitimate paid shortfall below the overdraft can save and recover; opening still requires the existing solvency and site checklist. Opening pays only the remaining staff/site/stock costs, with bands already paid.

Results/accounts expose actual ticket quantity, unit price, each sale/refund attempt, signed band releases and actual opening/closing cash. Historical journals preserve actual ticket facts used for expectations, relationships and popularity replay. Current and historical saves validate phases, quotes, roster membership, opening standing, cancellation history, deaths, accounts and carry. New Classic uses save namespace `r0-classic-v101`; old v100 saves are preserved and not silently migrated. Survival/Steward continue using the existing fixed tickets and preparation rules.
