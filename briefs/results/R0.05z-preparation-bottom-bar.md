Implemented 29 September 2026 as a separate user/producer-authorized presentation slice. The Build campaign now has one bottom preparation dock. Its five labelled pictogram destinations run **above** the accounting/Start row, in the approved Build, Programme, Staff, Equipment, Stock order. A selected destination uses teal; red exclamation badges derive only from actual `GetPreparationStartBlockers()` conditions. The full unpaid setup total, budget, remaining funds, payment timing, Start and focusable reason remain visible. People, Your Perks and Rotate view are in the subordinate dock group. Start uses the existing confirmation and command route; the original live HUD returns on start. No new graphic asset or simulation/accounting rule was introduced.

The separate readiness card shows concise specific reasons, with full authoritative text in tooltips and click-through destinations. It yields to the full-width Programme workspace and to a selected-object context card; visible card area blocks world placement input.
