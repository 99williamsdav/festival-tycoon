# M0.06 — Farm scene, camera and persistent overlay

Status at authoring: Not started. Milestone: M0 foundation.

## Assignment

An exported application shows a readable farm with four camera orientations and selectable simulation-backed objects.

Dependencies: M0.05 accepted.

Read [shared execution rules](README.md#shared-execution-rules), then these targeted sections of the repository-root documents: GAME_DESIGN_SPEC.md §§8, 16–17; TECHNICAL_SPEC.md §10; STYLE_STUDY.png (left panel). Read additional sections only when needed to resolve a concrete dependency.

## Scope

- Create a small low-poly blockout: field, hedge, road/track, farmhouse, barns, trailer stage, gate and service point. Use simple authored meshes/materials.
- Load positions and stable IDs from scenario/read models; picking must return authoritative IDs rather than mesh names.
- Orthographic angled camera with pan, bounded zoom and 90-degree rotation. Add mouse and button/key controls.
- Persistent cream-paper HUD for simulation time/pause and selection inspector; this is the seed of the final UI, not a complete UI kit.
- Record asset provenance, including original primitives.

## Acceptance checks

1. Launch Windows build and inspect all four orientations; selected object retains identity through rotation.
2. Picking the visible object opens the correct inspector; empty-space selection clears sensibly.
3. Camera movement and inspection leave the authoritative hash unchanged while paused.
4. HUD remains visible and controls usable at 1280x720 and 1920x1080; no clipped essential text.
5. Observe and capture screenshots of each orientation. Report visual checks as unverified if the environment cannot run/display the application.

These are required outcomes, not a prescribed test implementation. Add meaningful automated checks where feasible and report manual observations honestly.

## Exclusions

No moving crowd, full building editor, complex cutaways, production-quality art, music, weather or management screens.

## Demonstration

Pan, zoom, rotate four times, select farmhouse/gate/service point and inspect the HUD.
