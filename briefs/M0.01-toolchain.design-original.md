# M0.01 — Reproducible project and Windows build

Status at authoring: Not started. Milestone: M0 foundation.

## Assignment

A new developer can build a plain simulation library and launch an empty Godot Windows application using documented commands.

Dependencies: None. Start here.

Read [shared execution rules](README.md#shared-execution-rules), then these targeted sections of the repository-root documents: TECHNICAL_SPEC.md §§1–2; GAME_DESIGN_SPEC.md §§1–2; IMPLEMENTATION_PLAN.md §3. Read additional sections only when needed to resolve a concrete dependency.

## Scope

- Inspect available tools; choose and pin a compatible stable Godot .NET editor, SDK, export templates and test framework. Verify compatibility against official documentation at implementation time.
- Create the simulation library, console runner, test project and Godot application with the references described in the technical specification.
- Provide a minimal application that shows its build/version information; a runner prints a deterministic fixed smoke result and exits.
- Document prerequisite setup, build, test, run and Windows export commands. Use explicit tool paths/settings without assuming another agent's machine configuration.
- Ignore generated build/import directories. Create no speculative domain classes.

## Acceptance checks

1. Restore and build from the documented commands; runner exits successfully with expected output.
2. Build/reference inspection confirms the simulation library has no Godot package or assembly dependency.
3. Export a Windows build and launch it; report observed result separately from successful export.
4. A second build from cleaned generated output works without undisclosed editor steps. Delete only verified generated directories, preserving source and user files.

These are required outcomes, not a prescribed test implementation. Add meaningful automated checks where feasible and report manual observations honestly.

## Exclusions

No simulation loop, agents, navigation, UI framework, asset production or CI service setup.

## Demonstration

Launch the exported executable and the console smoke runner.

## Handoff and stop condition

Record exact versions and commands, export location, launch evidence and any environment limitations. Leave a short decision record explaining the selected version combination.
