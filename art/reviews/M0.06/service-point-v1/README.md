# Generic service point v1

Compact 4 x 3m rustic staffed kiosk candidate. The customer-facing -Y side has an open serving counter with shutter treatment, a blank changeable sign panel and a modest removable awning. A rear-side staff door communicates access without committing the kiosk to food, bar, merchandise, medical or another service type. Runtime nodes are Shell, Counter, Awning and Signage. Exterior only; no gameplay logic or detailed interior.

Source: `assets/source/environment/lwf_service_point_v1.blend`. Runtime: `assets/runtime/environment/lwf_service_point_v1.glb`.

The source reopens and the GLB reimports in Blender 4.1.1 with four runtime nodes and 372 triangles. Standard Godot 4.7.2 editor import completed successfully in the isolated check project. Review renders are six 1920 x 1080 orthographic views at approximately 35 degrees downward, including countryside and scale compositions. Gameplay identity, service type, queue slots, entrance and upgrades remain simulation-owned.
